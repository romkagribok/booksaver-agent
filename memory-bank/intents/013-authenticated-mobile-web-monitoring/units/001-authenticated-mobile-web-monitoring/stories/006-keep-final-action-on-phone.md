# Story: Keep the Final Booking Action on the User's Real Phone
**Global story ID**: US-088

As a user, I want BookSaver to hand off the offer to my phone so that I verify the actual signed-in mobile total and perform the irreversible action myself.

## Acceptance Criteria
- [ ] Handoff reminds the user to use the same signed-in account and verify total/refundability.
- [ ] VPS automation never completes cancel/reserve/checkout/payment.
- [ ] Product copy does not claim native-app or app-only discount coverage.
