# Story: Explain Every Authenticated Mobile-Web Price Source
**Global story ID**: US-087

As a user/operator, I want durable source provenance so that I can trust what context produced a price.

## Acceptance Criteria
- [ ] Success requires profile/channel/revision/auth/Genius/timestamp provenance.
- [ ] History/traces/alerts display non-secret source information.
- [ ] Cookies, account identifiers, and session query data never enter provenance.
