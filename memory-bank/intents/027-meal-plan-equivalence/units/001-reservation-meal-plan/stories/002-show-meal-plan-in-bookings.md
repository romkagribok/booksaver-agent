# US-217: Show the meal plan in /bookings

As a BookSaver user, I want `/bookings` to show the meal plan recorded for each reservation,
so that I can spot a wrong reading.

## Acceptance criteria

- Each reservation entry shows its meal plan in plain words.
- An `unknown` meal plan is shown as "meals not confirmed".
