# Story: Recover Visually Through Guarded Computer Use

## User Story

**As a** BookSaver user
**I want** a bounded visual fallback when semantic structure is unusable
**So that** a legitimate price check can survive severe presentation drift

## Acceptance Criteria

- [x] One Sonnet 5 episode receives screenshots and only the approved action tools.
- [x] Click coordinates are hit-tested; unsafe labels/links/popups/destinations fail before execution.
- [x] Every action receives a post-action destination/safety check and the episode stops by six actions.
- [x] All forbidden tool requests are typed refusals, and Opus never controls the browser.
- [x] Only typed price submission or a closed terminal outcome can end the loop successfully.

## Dependencies

- US-146 through US-148.

## Out of Scope

- CAPTCHA/MFA solving, credentials, file/system tools, or transactions.
