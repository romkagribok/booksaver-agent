# Existing terminal authority

PriceExecutionStatus already defines eleven closed non-observation statuses. The provider schema
advertises only an unrestricted string and the task/correction omit valid choices. Invented
statuses can cause repeated unmetered corrective responses. Expose the existing closed vocabulary;
never let the provider decide room equivalence, savings, or accept missing facts.

Agent cancellation currently bypasses its normal-return history diagnostic. Retain only bounded
code-owned action names/error categories and counts on interruption, preserving cancellation and
all deadline, cost, session, interaction and notification boundaries.
