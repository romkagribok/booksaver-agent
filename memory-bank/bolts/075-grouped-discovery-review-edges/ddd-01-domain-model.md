# Domain model

An arbitrary detail alias is not a reservation status card and cannot prove group loading is
finished. Readiness requires the exact expected count of distinct explicit status cards and
positively recognized non-hotels. Unknown targets remain inspectable after bounded waiting.

An inactive-only observed group is informational, not a provider failure. Empty-view evidence
requires known exact counts for every visited group, no root direct hotel targets, no active or
unparseable detail work, no unresolved work and positive inactive/non-hotel evidence. This never
proves account-wide absence or authorizes deletion of saved rows. Conflicting active/inactive
labels cannot establish inactivity. Authentication and safety stops override all observations.
